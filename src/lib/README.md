# `lib` structure

- `api/` — typed client functions for the Express API.
- `components/` — reusable presentation components shared by features.
- `features/` — domain-specific UI, state, and helpers.
- `stores/` — app-wide Svelte stores only.
- `types/` — shared frontend TypeScript types.
- `utils/` — small, domain-agnostic helpers.
