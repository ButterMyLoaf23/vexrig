# VexRig MVP Feature Inventory

The MVP for VexRig is focused on letting someone actually build and save a PC without adding a bunch of extra features that would make the project too big.

| Feature | What it does | Type | Depends on |
|---|---|---|---|
| F1 | Project & Database Setup | Infrastructure / supporting | None |
| F2 | User Registration & Authentication | Core feature | F1 |
| F3 | PC Parts Catalog | Core feature | F1 |
| F4 | Parts Search & Filtering | Core feature | F3 |
| F5 | Create & Edit PC Build | Core feature | F2, F3 |
| F6 | Build Price Calculation | Core feature | F5 |
| F7 | Build Compatibility Checking | Core feature | F5, F6 |
| F8 | Save & Delete Builds | Core feature | F2, F5, F6, F7 |

## What is included in the MVP

- Creating an account and logging in
- Browsing PC parts
- Searching and filtering PC parts
- Adding parts to a build
- Replacing or removing parts from a build
- Seeing the estimated price
- Checking basic compatibility
- Saving builds to an account
- Editing saved builds
- Deleting saved builds

## Features I am saving for later

These are good ideas, but I do not need them for the first version:

- Sharing builds with a link
- Build recommendations based on a budget
- A separate wattage calculator
- Favoriting or bookmarking parts
- 3D PC visualization
- FPS estimates
- Reviews or price tracking

Keeping these out of the MVP should make the project much more realistic to finish.
